# Instalar SimpleHealthTracker en el móvil

Incluido en el MVP: manifest de instalación, iconos para Android/iOS y apertura en modo independiente. Se utiliza el mismo servidor y la misma cuenta. Requiere internet; no incorpora almacenamiento offline ni notificaciones.

Tras desplegar el último commit en Vercel, abre la URL HTTPS de producción (no localhost ni una vista previa protegida).

## iPhone

1. Abre la web en Safari.
2. Pulsa Compartir y Añadir a pantalla de inicio. Si Compartir está dentro del menú de Safari, ábrelo primero.
3. Activa Abrir como app web si aparece esa opción.
4. Pulsa Añadir y abre HealthTracker desde su icono. Inicia sesión si lo solicita.

## Android

1. Abre la web en Chrome.
2. Abre el menú de los tres puntos.
3. Pulsa Añadir a pantalla de inicio y después Instalar (o Instalar aplicación, según la versión).
4. Confirma y abre HealthTracker desde el icono.

La instalación real en un dispositivo queda pendiente de la prueba del usuario. Si ya existía un acceso directo anterior, elimínalo y vuelve a añadirlo para actualizar icono/modo de apertura.

Fuentes: [Apple](https://support.apple.com/es-es/guide/iphone/iphea86e5236/ios) y [Chrome](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=es).
